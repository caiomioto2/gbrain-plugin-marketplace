# GBrain Workflows 0.2.0

Inclui as 69 skills de plugin/skills/ em garrytan/gbrain, commit d13aa742fd68b71bfd6c98be3dda5813791f1d6c, mais conventions e regras compartilhadas. Preserva os corpos das instruções originais, com contrato de adaptação para ChatGPT e frontmatter portátil.

O número 22 no README oficial indica skills com operações fora da superfície starter do MCP (29 operações nesse commit), não a quantidade de skills.

Requer o conector GBrain instalado e autorizado; este pacote não instala servidor nem contém credenciais. As instruções de instalação, manutenção, banco, cron e outros fluxos locais ficam condicionadas às ferramentas e permissões realmente disponíveis. O script de origem generate-plugin-tree.ts é uma ferramenta de build do repositório, não um comando do CLI gbrain.

Os oito workflows da versão anterior foram ampliados para a seleção oficial completa. O plugin preserva identidade, privacidade e prompts anteriores. Referências históricas da versão 0.1.0 permanecem no pacote, mas a instrução ativa vem do commit oficial citado acima.
