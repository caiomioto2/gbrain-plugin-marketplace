# GBrain Workflows para ChatGPT

Plugin privado com oito workflows adaptados do repositório caiomioto2/gbrain-plugin-marketplace, commit c3fa2177a2483e40720633e22d5f6fff339f9eda.

Requer o conector GBrain instalado e autorizado no ChatGPT. Este pacote não contém servidor MCP, credenciais ou vínculo automático com um app. Após instalar, invocar GBrain Workflows junto com GBrain numa conversa e testar uma consulta antes de usar escrita.

As referências de origem são preservadas, mas a execução no ChatGPT usa ferramentas disponíveis, schema ativo e escopo do pedido. Workflows administrativos que exigem acesso local não foram incluídos nesta primeira versão. A instalação do pacote não prova disponibilidade de todas as operações em cada conexão.
